# 🔍 0SINT - Professional OSINT Tool

Мощный инструмент для открытого поиска информации (OSINT), разработанный на Python.

## ✨ Основные возможности

- 🌐 **Анализ доменов**: WHOIS, DNS, SSL сертификаты (crt.sh), поддомены
- 🖥️ **IP Recon**: Геолокация, обратный DNS, сканирование портов
- 👤 **Поиск персон**: По никнейму и полному имени с интеграцией соцсетей
- 📧 **Email разведка**: Поиск по email адресам
- 🔗 **Интеграция API**: Shodan, VirusTotal, ipinfo.io
- ⚡ **Параллельная обработка**: ThreadPoolExecutor для быстрого сканирования
